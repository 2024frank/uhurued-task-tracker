# Surface Brief: Uhurued Task Tracker (`src/App.tsx`)

- **Mode:** Operate
- **Audience:** Collaborating software engineers and workspace leads across Uhurued projects.
- **Core Job:** Sign in via 6-digit email code from `tracker@uhurued.com`, view and work on assigned engineering tasks, generate detailed tasks from raw transcripts via local uncensored `qwen3.6-35b-a3b-heretic` (`127.0.0.1:8083`), share `.env` files and GitHub repo clone/setup instructions, and dispatch autonomous bug fixes via DeepSeek Harness (`dsh`).
